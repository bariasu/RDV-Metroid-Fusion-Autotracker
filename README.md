# Autotracker for Randovania Metroid Fusion

This autotracker is designed for Randovania's Metroid Fusion randomizer and BizHawk 2.9 or newer for Windows and Linux

**HOW TO USE:**

[Download RDVFusion_Autotracker_v1.4.zip from the Release Page](https://github.com/bariasu/RDV-Metroid-Fusion-Autotracker/releases/tag/v1.4)

-Extract RDVFusion-Autotracker-v1.4.zip, then place the extracted folder somewhere you can find it

-Open BizHawk, and open the randomized game

-In BizHawk, navigate to Tools > Lua Console

-In the Lua Console, navigate to Script > Open Script

-Browse to the RDVFusion-Autotracker-v1.4 folder, and choose whichever you prefer of the four .lua files

Which file you choose depends on:

A. which side of the screen you want the tracker on

B. if you want it to display the Level 0 Key. I included both versions because the Level 0 Key usually isn't shuffled outside of DLR.

That's all there is to it. The tracker won't appear on the screen until you have control of Samus, after the intial Adam/Computer text cutscene.
